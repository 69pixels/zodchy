## Анимации

Механика та же, что в Ular: один `scroll`-обработчик, каждая сцена считает прогресс по `getBoundingClientRect` обёртки (высота обёртки задаётся в JS в `layout*`). Сцен в Spadafy больше и они сложнее.

| Эффект | Реализация | Пресет |
|---|---|---|
| Заливка слов серый→белый (intro, break) | `splitWords` оборачивает слова в `.w`, класс `.on` по прогрессу; `setFillSequence` — одно предложение из нескольких элементов | `scroll-text-fill` (общий с Ular!) |
| Окно-маска в плашке | `clip-path: inset(... round ...)` + изображение, подогнанное под фиксированный фон | `mask-reveal` |
| Горизонтальная лента | `translate3d` по `easeIO` + линейная часть | `scroll-horizontal` |
| Подъём карточки + заливка | `translate3d`, прогресс через `easeOut` | `card-rise` |
| Стопка карточек | `max(natural, stackTop + i*step)` | `stack-sticky` |
| Анимированные карты (4 вида: desktops / customers / regions / timeline) | SVG-слои, `@keyframes fm-*` (twinkle, draw, pop, light, pulse), `setOpen(bool)` ставит на паузу и продолжает | компонент `map/dotted-world` |
| «Вписывание» кадра в контейнер | `clip-path: inset()` по прогрессу | `frame-inset` |
| Рисование знака S | `stroke-dasharray/-offset` по длине пути (`getTotalLength`), три фазы: пунктир → заливка по «хребту» → сплошной контур | `svg-draw` (уникальное, проектное) |
| Кроссфейд при pin | opacity + `scale(1.08→1)` + сдвиг текста | `scroll-pin/crossfade` |
| Въезд шагов с инерцией | rAF-цикл, lerp 0.12 | `glide-in` |
| Карусель по таймеру | CSS `tFill` + `animationend` | компонент |
| Переход на другую страницу по скроллу | рост карточки и авто-навигация | `transition/next-page` |

**Reduced motion — проблемная зона.** CSS-правило `prefers-reduced-motion` только сжимает `transition`/`animation` до 0,01 мс. JS-сцены (`renderIntro`, `renderTeam`, `renderBreak`, `renderFlags`, `renderServices`, `renderCare`, `renderNext`) на `mqReduce` не смотрят: pinned-сцены, горизонтальная лента и автопереход на `tech.html` работают так же. Заливка слов не имеет статичной версии. Корректно обработаны только отзывы (автосмена выключается) и инерция Health Check. В Ular reduced motion сделан полностью (статичные блоки). Для стартера нужна единая схема: пресет сам даёт статичный фолбэк.

## Токены в коде

- **Цвета:** `--charcoal #2f2f2f`, `--soft #f4f4f4`, `--white`, `--black`, `--pink #fc029c`, `--orange #ff521d`, `--panel-grey #515151` + альфа-варианты; хардкод: `#ff6a3b`, `#e0018b`, `#d4d4d4`, `#5b5b5b`, `#1a1a2e`, `#0ab574` (зелёный для карт).
- **Шрифты:** `--f-display` Review Condensed (заголовки), `--f-body` Aeonik. Aeonik Pro Regular в проекте нет, Medium подставлен вместо 400 (комментарий в CSS).
- **Сетка:** 12 колонок × 135, gutter 20, margin 40 на 1920; `--margin`, `--gutter`, `--col`.
- **Размеры:** 144 строки с `calc(N * var(--u))`, где `--u` = ширина вьюпорта / 1920 (выставляется из JS). Тот же приём, что в Ular (там делитель 1440). То есть дизайн масштабируется линейно, а не адаптивно; отдельная сетка на мобильных (`--m:16px`).
- **Тайминги/кривые:** `--ease-out`, `--ease-io` вынесены, остальное числами (`.2s`, 7000 мс и т. д.).
- **Брейкпоинт:** один, 820 px, против принятых 1440 / 1024 / 768 / 375 (у Spadafy ещё 1920 как базовая ширина макета).

## Костыли и риски

1. **JS управляет высотой секций** (`team.style.height = …`, `svc.style.height = …` и т. п.) и пересчитывает при `resize`, `load`, `fonts.ready`, `load` картинки. Хрупко, возможны прыжки при ленивой загрузке.
2. **Автопереход на `tech.html` при скролле до 99,5 %.** Пользователь, который долистал страницу, неожиданно уходит на другую; нет ни ссылки-альтернативы для клавиатуры (есть `<a class="next-card">`, но фокус не гарантирует аналог), ни учёта reduced motion.
3. **Reduced motion не покрывает JS-сцены** (см. выше).
4. **Магические числа** в расчётах сцен (`.63`, `.12`, `.77`, `1.25`, `3.4`, `2.6` и т. д.) без именования; параметры сцен не вынесены в `data-` атрибуты.
5. **Данные карт сгенерированы** из React-компонента (`dotted-world-map.points.ts`), которого в репозитории нет — воспроизвести генерацию нельзя. Карты показывают «representative locations, not real customer data» (комментарий в коде): честные данные клиента нужны для продакшна (`TODO(human)`).
6. **Отзывы и данные в JS** (`TESTIMONIALS`), часы Сиэтла — клиентский JS; без JS блок пустой.
7. **Hero — картинка, не видео.** В README: заменить `<img>` в `.hi-bg` на `<video>`. Что именно в Figma — коллаж из фото (чёрный фон, плитки) — сверять с `hero-bg.jpg` нужно отдельно; на обзорном скриншоте hero выглядит иначе, чем «разовая картинка» (`TODO`).
8. **Ссылки соцсетей и юр. страниц — заглушки** `href="#"`; нет формы, только `mailto:`.
9. **Один язык (EN)**; шрифт Review Condensed — лицензия неизвестна (`TODO(human)`); Aeonik Pro Regular отсутствует.
10. **История репозитория** — загрузка файлов и удаление папки, без веток по версиям (кроме одной feature-ветки).
11. **Нет страницы «The Tech»** — только заглушка; страница `991:2713` в Figma не размечена как готовая.
12. **Доступность:** есть skip-link, ARIA у меню и карусели, `aria-live` у номера услуги и цитаты, `aria-hidden` у не активных блоков Care. Нет focus trap и `aria-modal` у меню; ссылки «Learn more →» одинаковые и ведут на `#contact`; у карточек команды нет ссылок на людей.
13. **Тяжёлые карточки команды:** 8 JPG + 6 фото услуг + 3 care + 4 flag-map PNG без `srcset`/WebP.

## Что кандидаты в библиотеку

Высокий приоритет (повторяются, в том числе уже в Ular):
1. `scroll-text-fill` — **общий с Ular** (там «Миссия», тут Intro и Break). Разные реализации (Ular — градиент `background-clip:text` через `--fill`, Spadafy — класс `.on` на слове). Взять один вариант + два оформления.
2. `scroll-pin/steps` и `crossfade` — pinned-сцены (Ular «Ценности» ≈ Spadafy «Care»; Ular «Направления» ≈ Spadafy «Services» по классу сложности).
3. `nav/pill-collapse` + меню-панель (Ular: прячущийся хедер + мобильное меню; Spadafy: 3 состояния) — один компонент Nav с вариантами.
4. `carousel/timer` (Spadafy отзывы) ↔ Ular новости-свайп — разные паттерны, но один контейнер.
5. `stack/cards-sticky`, `scroll-horizontal/track`, `steps/glide-in`.
6. `map/dotted-world` (Spadafy) и `map/dots-regions` (Ular) — точечные карты на разной технике (canvas vs SVG), общая идея; в стартер — один компонент с режимами.

Проектное, не в стартер: знак S и его отрисовка (`mark/s-draw`), «The Tech» transition, контент, карточки команды.

## План переноса в Astro (черновик для spec)

1. Токены: цвета, шрифты, шкалы; сетка 12 × 135 → CSS grid с брейкпоинтами; убрать `--u` из JS в пользу CSS-единиц (например `clamp()`/`cqw`).
2. Сцены на GSAP ScrollTrigger (pin, scrub, timeline) вместо ручных расчётов высот; каждый пресет имеет статичный фолбэк при reduced motion.
3. Контент в `src/content/` (команда, услуги, отзывы, флаги); карты — данные в JSON, не генерация из внешнего репозитория.
4. Меню — компонент Graphical (Dialog/Drawer) с focus trap или осознанная альтернатива.
5. Автопереход по скроллу — заменить на явный CTA/ссылку (решение — `DECISIONS.md`).
6. Ассеты: WebP/AVIF + `srcset`, шрифты WOFF2.
