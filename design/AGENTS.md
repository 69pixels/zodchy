# design/ — правила для агентов

Общие правила — в корневом `AGENTS.md`. Здесь только то, что касается этой папки.

## Что здесь
Кэш Figma: `design/<проект>/…png`. Это эталон для сверки скриншотов, а не рабочая папка.

## Правила
- Файлы только из Figma (экспорт или `get_screenshot`). Руками не правим.
- Имя файла: `<устройство>-<секция>-<ширина>.png` (например `desktop-companies-1440.png`) или `<узел>-<что>.png`.
- Для каждого файла указываем fileKey и node-id в `design/<проект>/README.md` (дата выгрузки, ссылка).
- Читаем Figma экономно: `get_metadata` → точечный `get_screenshot` по node-id. Не выгружаем всё подряд.
- Если `get_metadata` по большому узлу падает или слишком велик — идём по подузлам и страницам, не повторяем тот же запрос.
- Обновляем только изменившиеся фреймы, остальные не трогаем.
- Размер: один файл до ~2 МБ; крупные раскадровки сжимаем (`maxDimension`).

## Чего не делать
- Не класть сюда ассеты для вёрстки (картинки сайта) — они живут в проекте.
- Не коммитить временные URL от Figma (они короткоживущие).
