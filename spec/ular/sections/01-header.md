## Задача секции
Дать быстрый доступ к разделам страницы и CTA, не мешая просмотру: уходит при скролле вниз, возвращается при скролле вверх.

## Контент
- Логотип ULAR (знак + вордмарк, SVG) → `#top`.
- Пункты (моно, uppercase): О компании · Структура · Локации · Новости · Контакты.
- Переключатель языка: РУ / KK / EN (в прототипе `details` с одним «Русский ✓» и сообщением «Другие языковые версии пока недоступны»; в проде рабочий).
- Кнопка «Написать нам» (белая) → `#contact`.
- Мобильное меню: те же пункты + оранжевая кнопка «Написать нам».

## Раскладка
- Desktop: высота 94 px, поля 60 px; логотип слева, меню по центру (абсолютное), справа язык + кнопка.
- Tablet: как mobile.
- Mobile: высота 58 px, логотип + бургер 24×24 (три полоски → крестик); меню на весь экран с отступом сверху 98 px.

## Состояния и интерактив
- Ссылки: hover → цвет акцента. Кнопка: hover → `accent-hover` и сдвиг вверх на 2 px.
- После 8 px скролла: полупрозрачный белый фон + blur 22 px + тонкая нижняя линия.
- Скрытие/показ — см. «Моушн». Не скрывается при фокусе внутри, открытом языке и открытом меню.
- Язык: открытие по клику, закрытие по клику вне; стрелка поворачивается на 180°.
- Мобильное меню: `aria-expanded`, закрытие по клику на ссылку, Esc, возврату на десктоп; при открытом меню скролл страницы блокируется.

## Моушн
- Появление: нет.
- Скролл-поведение: `translateY(-100%)` при скролле вниз (>4 px, y > 120), возврат при скролле вверх; 0,4 с `cubic-bezier(.2,.7,.2,1)`.
- Раскадровка в Figma: нет (`TODO(human)`).
- Reduced motion: переход отключён.
