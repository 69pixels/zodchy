## Навигация и переходы
- Меню: «О компании» → `#about`, «Структура» → `#companies`, «Локации» → `#locations`, «Новости» → `#news`, «Контакты» → `#contact`; кнопка «Написать нам» → `#contact`; логотип → `#top`. Skip-link «Перейти к содержанию» → `#mission`.
- Поведение хедера при скролле: fixed; после 8 px фон с blur; при скролле вниз >120 px прячется, при скролле вверх (>4 px) возвращается; не прячется, пока в фокусе, открыт переключатель языка или мобильное меню.
- Плавный скролл: `scroll-behavior: smooth`, `scroll-padding-top: 24px`; без снэпа.
- Переходы между секциями: обычный поток; две pinned-сцены («Ценности», «Направления»), см. файлы секций.

## Глобальный моушн
- Пресет появления по умолчанию: `reveal-up` (смещение 18 px, 0,65–0,7 с, задержки 0 / 0,1 / 0,2 с) — только на hero; остальные секции появляются без анимации входа.
- Особые сцены: pinned «Ценности» (sticky, высота экран + 105 svh) и «Направления» (sticky, высота stage + 85 svh); заливка текста «Миссия»; hero-видео.
- Reduced motion: все CSS-анимации отключены; «Миссия» залита целиком; «Ценности» и «Направления» превращаются в статичные блоки (без sticky); видео на паузе; JS-эффекты (отталкивание точек, плавная прокрутка к вкладке) отключены.

## Адаптив
- Брейкпоинты: 1440 / 1024 / 768 / 375. Прототип делит только по 1023 px (десктоп / мобильный).
- Особые правила: планшет (768–1023) получает **мобильную раскладку**, отдельного макета нет. Мобильные макеты 375 px есть в Figma (секция `Mobile`, `2879:8021`). Поля 60 px на десктопе, 16 px на мобильном.
- Особенности мобильной версии: бургер-меню на весь экран; «Ценности» — стрелки, счётчик, свайп; «Направления» — карточки по 2 в ряд, только логотипы, панель бренда как bottom sheet; карта — табы регионов и карточка адресов под картой; новости — свайп-карусель с точками.

- CMS, сторонние сервисы, аналитика — не входят.
